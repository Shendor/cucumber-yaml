Messaging Test Case property

Indicates a RMQ, IBMMQ or TCP channel name (reference) where the request is sent.
The value is a reference to the channel, registered in a .conf file of Chronos configuration where all details of this channel is configured (ex. credentials, connections, etc.)
If the channel name is referenced in many channel details in .conf file, (ex. queues from different nodes), then it will send the request to each of them
