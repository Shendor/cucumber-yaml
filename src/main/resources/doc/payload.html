A payload for the test case (optional).
The payload is converted to json automatically when processed, unless the property 'format' is defined.
The payload is represented as Map<String,String> or List<Map<String,String>, thus it can be converted to json by the default serializer, or passed to a serializer defined in 'format' property.
Then, this serialized payload (ex. String) is processed based on the logic of the specific test case.
(ex. if it's HTTP-based test case, then it's transferred as body of the request)
