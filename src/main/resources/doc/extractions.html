Extract value from the result of test case execution and stores it in the local test storage in memory, so it can be extracted in other YAML test case using 'get' function, for example:

For any type of result, you can extract values by json path, for example:

- extractions:
field1: #jsonPath(response.body, a.b.c)
field2: #jsonPath(response.body, a.d[0])

If result is a List of Map, then a value can be extracted this way:

- extractions:
field1: response[0][key_a]

'response' property is mandatory as it stores the actual result of test case execution.
