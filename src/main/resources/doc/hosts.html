Log or Shell Command Test Case property

A list of hosts. It is a not an actual host name of your remote machine (VM), but a name which you use when configuring Log Test Case Processor or Shell Command Test Case Processor in the Chronos configuration, where you provide connections details (ex. SSH) for each remote VM and link it to a unique host name, which you can reference here.
You can register as many VMs in the Log Test Case Processor or Shell Command Test Case Processor as you need and reference them in YAML test cases. For example:

hosts:
- host_A
- host_B

or
hosts: host_A,host_B
