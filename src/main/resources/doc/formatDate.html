Instantiates a current date and time and formats it in specified format, for example:
field1: formatDate(yyyy-MM-dd)
field2: formatDate(yyyy.MM.dd)
field3: prefix_formatDate(hh:mm)
field4: formatDate(yyyy-MM-dd'T'HH:mm:ss'Z', UTC)
field5: formatDate(yyyy-MM-dd'T'HH:mm:ss'Z', US/Samoa, tomorrow)
field6: formatDate(yyyy-MM-dd'T'HH:mm:ss'Z', UTC, 5 days ago)

for field5 and field6, in 3rd parameter you can set a modificator, to indicate the difference from the current date.
