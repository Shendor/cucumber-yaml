DB Test Case property

This payload is represented as a list of columns, which is used to compose a SQL query when processing this test case.
In this particular example, the composed query will look like this (if 'sql' property not defined)
SELECT * FROM table_a WHERE columns_a:=column_a AND column_b LIKE %:column_b% AND column_c <= :column_c
and the parameters are assigned based on their names.

- test: find data
db_command: find
table: table_a
expected columns:
column_a: value 1
column_b: %value 2%
column_c:
comparator: "<="
value: now(UTC)
