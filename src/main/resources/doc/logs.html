Log Test Case property

A list of log files per host. The host is a not an actual host name of your remote machine (VM), but a name which you use when configuring Log Test Case Processor in the Chronos configuration, where you provide connections details (ex. SSH) for each remote VM and link it to a unique host name, which you can reference here.
You can register as many VMs in the Log Test Case Processor as you need and reference them in YAML test cases, to indicate which logs to find the records from. For example:

logs:
- host: host_A
log: home/user1/log1.txt
- host: host_B
log: home/user2/log1.txt

another way to do it:
hosts: host_A,host_B
logs: home/user1/log1.txt,home/user2/log1.txt

if you need to search in one file:
host: host_A
log: home/user1/log1.txt
