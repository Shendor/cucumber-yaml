Log Test Case property

A log file path for a host. The host is a not an actual host name of your remote machine (VM), but a name which you use when configuring Log Test Case Processor in the Chronos configuration, where you provide connections details (ex. SSH) for each remote VM and link it to a unique host name, which you can reference here.
You can register as many VMs in the Log Test Case Processor as you need and reference them in YAML test cases, to indicate which logs to find the records from. For example:
host: host_A
log: home/user1/log1.txt
